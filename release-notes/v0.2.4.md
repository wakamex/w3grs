Replays from patch 2.0.2 on send `BlzSendSyncData` as raw action 0x77: two zero-terminated strings and four bytes. w3grs read it with the older `W3Api` layout, took its string bytes for a buffer length, and dropped every action after it in the same command block, orders included. It now reads 0x77 as `BlzSync` in those replays. In the 50-replay probe corpus, 478,560 of 478,581 command blocks now parse to their exact end, up from 478,548.
