A pause action (0x01) carries no data, like resume (0x02). w3grs skipped one byte after it, so a pause at the end of its command block ran off the block's end and was never classified. It now reads no payload after a pause, and with the `extended-actions` feature it emits the pause as an `OpaqueDroppedAction`, as it already did the resume, so a consumer can tell which game time a pause held. Default output is unchanged.
